# Secure E-Voting System

Matdaan is a web-based electronic voting system developed using ASP.NET, C#, Microsoft SQL Server, HTML, CSS, and JavaScript. The platform provides a secure and organized solution for conducting online elections with dedicated panels for administrators and voters.

The system was designed to simulate a real-world digital election environment where administrators can manage elections and voters can securely participate in voting.

## Tech Stack

Backend  
ASP.NET (C#)

Database  
Microsoft SQL Server

Frontend  
HTML  
CSS  
JavaScript

Version Control  
Git and GitHub

## Features

### Administrator Panel

- Administrator authentication and login
- Create and manage elections
- Add, update, and remove candidates
- Manage voter information
- Monitor voting activity
- View election results and declare winners

### Voter Panel

- Voter registration and login
- Secure voting system
- One-person-one-vote mechanism
- Participation in active elections
- View election results

## System Objective

The goal of this project is to demonstrate the development of a secure online voting platform using ASP.NET and SQL Server while implementing proper database design, user authentication, and role-based access for administrators and voters.
